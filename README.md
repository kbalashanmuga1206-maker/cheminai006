# Molecule Studio AI – Version 2.0

An AI-powered educational chemistry laboratory.

## Features
- SMILES validation
- 2D molecular visualization
- Molecular properties
- Six-molecule comparison
- 3D conformer generation
- AI Chemistry Tutor
- PDF reports
- Chemistry quizzes

## Technologies
- Python
- Streamlit
- RDKit
- Pandas
- OpenAI API
- ReportLab

## Installation

Install Python 3.10 or 3.11.

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Enable AI Tutor

Add your API key to Streamlit Secrets:

```toml
OPENAI_API_KEY = "your_api_key_here"
```

## Deployment

1. Upload all project files to GitHub.
2. Open Streamlit Community Cloud.
3. Select your GitHub repository.
4. Set the main file to app.py.
5. Deploy the application.
